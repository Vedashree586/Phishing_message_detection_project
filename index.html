LINK STRUCTURE

  • Link destination is deceptive +20
  • Brand name doesn't match link +16

REQUESTS FOR SECRETS OR MONEY

  • Asks for credentials or codes +24
  • Requests identity verification +20
  • Requests payment or gift cards +26
  • Asks for sensitive personal data +16
  • Asks you to buy something for them +28
  • Pushes an attachment or download +12

Repetition adds points. Each extra distinct match of the same rule adds up to +4, so a message that repeats a tactic scores higher.

One keyword is not a verdict. When only a single indicator is triggered, the score is capped at 44 so the message cannot be labelled High Risk on one word alone.

Phishing Awareness & Security Guide

Master the primary tactics modern attacker campaigns use to steal access credentials and funds.

1. Manufactured Urgency

Phishers rush victims with immediate deadlines ("Account locked in 2 hours") to cause anxiety and force hasty actions before verifying authenticity.

2. Spoofed Domains & Typos

Look closely at links! Domain names like chase-secure-login.top or paypaI.com (using a capital 'I' for 'l') impersonate official domains.

3. One-Time Code (OTP) Theft

No bank or customer service agent will ever request your 2FA OTP over email, phone, or direct text message. Treat OTPs like your master password.

4. Malicious Attachments

Be cautious of unexpected .html, .zip, or double extension attachments like Invoice_Oct.pdf.exe that execute malware locally.

PhishGuard Security Analyzer

VSEC Mini-Project Prototype · Rule-Based Architecture

Project Architecture

PhishGuard is a privacy-first, client-side phishing threat analysis prototype. It evaluates raw text content, email headers, SMS messages, and hyperlinks using a deterministic, rule-based heuristic scoring model.

Core Principles

    Zero Server Uploads: Text processing is executed locally in JavaScript in your browser memory. Transparent Rules: Every rule match is explicitly attributed with weighted scores and matched keywords. No AI Black Boxes: Scoring thresholds (0-29 Low Risk, 30-59 Suspicious, 60-100 High Risk) are fully documented.
